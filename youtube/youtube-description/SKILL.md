# YouTube Video Description — Ionio Standard

## Positioning Context

Ionio is a specialized AI consultancy working exclusively with retail and e-commerce SaaS platforms ($5M-$100M ARR). The tone across all Ionio content is practitioner-level, confident, and premium. Descriptions must reflect this. They are not casual creator descriptions. They represent a company that has shipped 40+ products across 45+ clients and publishes deep technical research.

Every description must feel like it was written by someone who builds production AI systems, not someone trying to game the algorithm.

## Hard Copy Rules (Apply Everywhere)

- Never use em-dashes anywhere in the description.
- Never use "No X. No Y. No Z." negation list patterns.
- Never use emoji anywhere.
- Never use casual creator language ("Hey guys", "In today's video", "Don't forget to like and subscribe", "Hit the bell icon").
- Never write stat-dump sentences like "45+ clients. 40+ products shipped." This reads like a desperate LinkedIn bio, not a premium consultancy. Stats belong inside narrative prose, not as standalone fragments.
- The "In this video" section is always written in first person. Rohan is the one writing/speaking. It's "I break down..." or "We walk through..." — never "Rohan breaks down..."
- All copy must have taste. If it reads like something any AI agency could have written, rewrite it.

## Description Structure (Strict Order)

### Section 1: CTA Links (Above the Fold)

These three lines are the only thing visible before "Show more." Clean and direct.

```
Book a consultation: https://calendly.com/rohansawant/intro
Website: https://www.ionio.ai
Email: contact@ionio.io
```

Rules:
- Exactly three lines. Nothing else above the fold.
- No emoji prefixes. Clean text only.
- This block is identical on every video. Never changes.

### Section 2: About Ionio

A fixed block on every video. This is the brand paragraph. It must read like considered prose, not a feature list.

```
Ionio is a specialized AI consultancy for retail and Ecom SaaS. We transform mid-market Retail & Ecom SaaS ($5M-$100M ARR) platforms into AI-native category leaders by building strategic AI features that deliver immediate ROI for merchants, allowing you to justify premium pricing & increase LTV. Over five years, we've built and launched over 40 products across 45+ companies.
```

Rules:
- This block is identical across all videos. Never customize it. Use this exact copy.
- Confident but not boastful. Stats are woven into the final sentence, not listed as fragments.

### Section 3: LinkedIn

A single line linking to Rohan's LinkedIn. Sits after the Ionio paragraph, separated by a blank line.

```
Rohan on LinkedIn: https://www.linkedin.com/in/rohan-sawant-code
```

### Rotation Logic

When selecting 5 videos for a description:
1. Identify which playlist the current video belongs to.
2. Select 2 videos from the same playlist (not the current video).
3. Select 3 videos from the other playlist.
4. Randomize the order of all 5.

If the current video doesn't belong to either playlist, select 2-3 from each and randomize.

### Section 5: In This Video

2-3 sentences describing what this specific video covers. This is the only section that changes per video.

Format:
```
In this video:
[2-3 sentences in first person]
```

Rules:
- Always first person. "I walk through...", "We cover...", "I break down..."
- Be specific. Name the actual concepts, frameworks, companies, or technical decisions discussed.
- This is where keywords live. Weave target keywords into the prose naturally. Never list keywords separately anywhere.
- Write at a practitioner level. The reader builds software or runs a SaaS company.
- The copy should have a pulse. It should make someone want to hit play. Not just describe what happens, but signal why it matters.
- Avoid comma-chain sentences that list four or five concepts separated by commas. If you catch yourself writing "covering X, Y, Z, A, and B" in a single sentence, break it up. Each idea gets its own sentence. Comma chains are the single biggest AI-writing tell.
- Read the copy back. If it sounds like a press release or a ChatGPT summary, rewrite it. It should sound like a person talking about their own work.

### Section 6: Hashtags

Exactly 3 hashtags. Lowercase. Single line. One blank line of spacing above.

- First hashtag is always #ionio.
- Other two are topic-specific and searchable.

Example: `#ionio #ragsystems #enterpriseai`
Example: `#ionio #ecommerceai #retailpersonalization`

## What NOT To Do

- Do not add timestamps unless the video is 15+ minutes with clearly distinct sections.
- Do not add a separate "Keywords:" or "Tags:" section.
- Do not write stat-dump copy. Every number must live inside a real sentence.
- Do not use generic filler or creator-speak.
- Do not use third person when describing what happens in the video.
- Do not use em-dashes.
- Do not use "No X. No Y. No Z." patterns.
- Do not use emoji.
