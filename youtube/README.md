# YouTube

Skills for publishing on the Ionio YouTube channel: packaging, metadata, and positioning for each upload.

## Ledger

| Skill | What it does | Use when | Files |
|---|---|---|---|
| [youtube-title](youtube-title/SKILL.md) | Sorts a video as regular or testimonial, then writes title options that fit the channel's positioning and match proven title archetypes | You paste a transcript or description and need a title, title options, or the next number in a series | `SKILL.md`, `references/title-bank.md` |
| [youtube-description](youtube-description/SKILL.md) | Writes descriptions in Ionio's fixed 6-part order: CTA links above the fold, About Ionio, Rohan's LinkedIn, rotating library videos, a first-person "In this video", and hashtags | You're writing or batch-updating descriptions for Ionio uploads | `SKILL.md` |

## Reference files

- `youtube-title/references/title-bank.md`: an example bank of fictional titles, grouped by type and archetype. Use it to match a proven title shape. **Replace or extend it with your channel's own published titles**, which the skill prefers when you provide them.

## How they fit together

For each upload: run **youtube-title** on the transcript, then **youtube-description** for the same video. For written copy outside YouTube, see [`../copywriting`](../copywriting/README.md).
