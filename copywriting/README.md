# Copywriting

Voice and craft skills for any written copy that no other department's skill covers.

## Ledger

| Skill | What it does | Use when | Files |
|---|---|---|---|
| [hormozi-writing](hormozi-writing/SKILL.md) | Writes or rewrites copy by combining Hormozi-style persuasion with Mannan's voice rules (no em-dashes, no AI-sounding phrases, one idea per line). Includes a de-AI pass and adapters for each format | LinkedIn posts, white papers, landing pages, ads, video scripts, hooks, newsletters, or "make this sound human / punch this up" | `SKILL.md` |

## Scope

- Cold emails for Loom videos: use [`sales/loom-email-copy`](../sales/loom-email-copy/SKILL.md).
- YouTube titles and descriptions: use [`youtube/`](../youtube/README.md).
- Everything else written in Mannan's voice: use this folder.
